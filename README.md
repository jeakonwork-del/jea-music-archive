# JEA MUSIC ARCHIVE

제곤 님의 개인 음악·DJ 지식 베이스 웹사이트입니다.
인스타그램에서 저장한 음악 관련 피드(디제잉 스킬, 전자음악 행사·축제, 트랙 큐레이션, 곡 트렌드)를
정리해 한 페이지에서 검색·열람할 수 있게 만든 정적 사이트입니다.

## 구성

- `index.html` — 사이트 본체 (HTML + CSS + JavaScript 한 파일, 빌드 과정 없음)
- `data/archive.json` — 아카이브 데이터 (카테고리·태그·요약·수록곡·링크)
- `.nojekyll` — GitHub Pages가 Jekyll 처리를 건너뛰도록 하는 빈 파일

## 사용법

- 검색창: 제목, 아티스트, 태그, 요약, 수록곡까지 한 번에 검색
- 카테고리 탭: 전체 / 디제잉 스킬 / 행사 · 축제 / 트랙 큐레이션 / 곡 트렌드
- 카드의 "수록곡 N곡 펼쳐보기"로 트랙 리스트 확인
- "Spotify 플레이리스트 열기", "원본 인스타 피드" 버튼으로 원본 이동

## 데이터 추가

`data/archive.json`의 `items` 배열에 항목을 추가하고 `updatedAt`을 갱신하면 됩니다.
형식은 기존 항목과 동일하게 맞추면 되고, `tracks`는 없어도 됩니다.

## 배포

GitHub Pages (`main` 브랜치 / 루트)로 배포됩니다.
